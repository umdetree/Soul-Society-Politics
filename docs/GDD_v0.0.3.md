## 1. 游戏定义

**一句话定义。** 《瀞灵廷》是一款以人物、组织、门阀与职位竞争为核心的长期社会模拟 RPG。

**项目定位。** 市面上已有大量政治模拟与人物关系模拟游戏，但没有以护廷十三队为背景的长期人物政治模拟——这是做本作的理由。差异化不是"加一层情报系统"，而是两件事的结合：**强者政治 + 长周期人物史**。这意味着超自然武力体系——灵压、斩魄刀、始解与卍解、鬼道、修炼——必须占据比一般政治模拟大得多的比重：它既是个人成长的路径，也是政治威慑的来源，不能被当作附属的战斗模块。

**玩家扮演谁。** 玩家扮演一个具体人物，生活在一个由大量自主 NPC 构成的超自然军事官僚社会中。玩家不统治国家，不扮演抽象势力，不扮演历史本身。玩家能做的事——修炼、学习、执行任务、结交人物、加入派系、争夺职位、培养弟子、经营家族关系——NPC 都能做；玩家会经历的——受伤、老去、死亡、失去职位——NPC 也会经历。

**核心幻想。** 从一个无名之辈成长为足以改变整个瀞灵廷权力结构的人。这里的"成长"有四个维度：个人实力、社会关系、组织职位、家族与派系影响力。四者互相独立又互相转化：玩家可能是最强的人，却在政治上毫无根基；也可能实力普通，却通过师承、婚姻、门阀与人情进入权力中心。"实力很强、出身低微、军功卓著、被贵族忌惮、获得基层死神支持、与中央机构关系恶劣"本身就是一种合理的人生。

**核心体验。** 游戏的核心体验不是完成预先设计的主线，而是：作为一个具体的人，在一个长期自行运转的政治社会里留下自己的轨迹。世界不会等待玩家。

**玩家的特殊之处。** 玩家角色原则上只是世界中的一个普通角色，不存在特殊对象或特权体系。玩家唯一合理的优势，是跨几十年的连贯意图——这是 AI 天生不具备、人类玩家天然具备的东西。任何试图给玩家数值特权、系统豁免或剧情保护的方案，默认不通过评审。

**非目标。** 第一阶段明确不做：开放世界的自由探索地图、复杂 3D、实时动作战斗、大量手写主线剧情、精细经济模拟、国家级战争模拟、海量技能表、完整原作剧情复刻。所有新增系统都要先回答一个问题：它是否让人物之间产生更有意思的长期互动。答案是否定的，优先级就低。

**最终判据。** 当所有其他依据都无法决定时，使用北极星问题（见第 3 章）作为取舍标准。

## 2. Canon 与时代政策

**原创时代。** 游戏的故事发生在原创时代，由原创人物构成主要政治格局。

**采用原作世界观与制度语义。** 护廷十三队、番队、队长与副队长、席官、贵族门阀、中央机构、学院、隐秘组织等概念与语义，沿用原作设定，以保证世界观的可读性与代入感。制度的"名字与含义"来自原作，制度的"运行与历史"由模拟产生。

**原作人物与历史不是默认约束。** 游戏不保证任何原作事件发生，不保证原作人物出现、存活或死亡，也不以复述原作剧情为目标。世界历史由模拟产生，而不是由原作剧情牵引。

**设定材料的归属。** 时代起点、势力初始配置、原创家族与人物名录，属于内容设定文档，不在本文件中定义。

**边界说明。** 本政策规定的是默认形态，不排除未来以其他内容形态提供不同起点（见 OQ-01、OQ-02）。

## 3. 五项设计支柱

支柱是取舍的最终依据。任何系统设计如果与支柱冲突，应当先修改支柱或放弃该系统，而不是让支柱为系统让路。

### 第一支柱：NPC 是人物，不是事件素材

每一个 NPC 都必须拥有自己的身份、能力、性格、欲望、关系、职位、资源和秘密。NPC 自主采取行动：不是因为玩家触发了某个事件，所以 A 和 B 发生冲突；而是因为 A 想晋升、B 占着职位、A 与 C 有关系、C 掌握 B 的秘密，于是自然形成一连串事件。这是整个游戏最重要的设计原则。

### 第二支柱：时间使成长、关系和权力产生机会成本

修炼不是按钮，政治经营也不是白嫖。玩家决定闭关三年学习卍解，代价就是三年真的过去：好友可能升职，导师可能死亡，竞争对手可能成为副队长，家族可能衰退，队长可能下台，新的派系可能形成。时间不是背景音，而是所有长期决策的成本单位；力量成长、关系维护与权力经营之间的取舍，构成长周期游玩的底层张力。

### 第三支柱：个人实力是政治秩序的一等基础，但实力不能自动解决政治问题

在这个世界里，强者不是"比较能打的人"，而是秩序本身的一部分：一个人可能强到足以对抗几十名普通死神，一个队长级人物本身就是军事资产，制度必须考虑"这个人如果不同意怎么办"。因此政治资本可以从两个方向产生：自上而下——个人武力、威慑、不可替代性与维稳能力；自下而上——家族、人脉、功绩、资历、派系与合法性。

反过来，最强也不等于万能：治理需要人手与制度，合法性需要承认，信息不会自动汇集，一个人无法同时出现在所有地方。政治根基深而实力不足者必须扶植强大的代理人；实力极强而政治孤立者可能始终无法进入权力核心。即便是中立维稳型的权威，其约束力通常也以压倒性的实力为后盾（世界顶层设定中的此类力量是否作为模拟实体存在，见 OQ-02）。这两类人物都会自然产生故事。

### 第四支柱：失败也必须产生历史

被击败不是 Game Over，而是一次人生轨迹的改变。竞争副队长失败，可以变成与胜者关系恶化、被调离原番队、进入另一个组织、结识新的派系、十年后重新回来。重伤、降职、流放、家族衰落、师父死亡，都应当产生新的处境与新的故事，而不是单纯的惩罚。

### 第五支柱：因果必须可追溯

世界发生的重要变化，必须能够追溯到人物过去的经历、认知、目标和行动，并且让玩家理解为什么。十年前玩家抢走了某人的晋升机会，十年后那个人进入另一个派系、积攒权力、阻止玩家成为队长——这条链条上的每一环，都应当能被查询、被解释、被玩家理解。

### 北极星问题

> **世界发生的重要变化，能否追溯到人物过去的经历、认知、目标和行动，并让玩家理解为什么？**

这是本项目的最终判据，也是整个模拟系统在技术上的核心目标之一：可解释性（explainability）。对"为什么发生"的回答，必须是一份支持与反对因素的清单，而不是一个不透明的综合分数。只给分数不给理由的系统，视为未完成。

## 4. 三层世界模型

本项目的世界被严格划分为三层，任何系统都必须明确自己工作在哪一层。三层不得混用，这是架构纪律，而不是实现建议。

**世界真相（World State）。** 世界的客观状态：所有人的属性、关系、秘密、计划、记忆与历史。真相只有一个，且不因谁在观察而改变。

**角色认知（Knowledge）。** 每个角色（包括玩家角色）对真相的掌握，是真相的子集。认知带有来源与置信度：我知道某件事，是因为我亲眼所见、有人告诉我、还是我推断出来的。玩家知道的，不等于世界的真相。

**玩家呈现（Presentation）。** 经过选择、延迟和包装之后，交给玩家的信息：编年史、密报、传闻、对话、事件文本、界面数据。它是玩家与真相之间的唯一通道。

### 三条铁律

1. **NPC 不得全知。** 任何 NPC 的行动，只能基于其认知层掌握的内容。NPC 不能"因为剧本需要"知道它不可能知道的事。
2. **呈现层不得发明真相。** 事件文本只能搬运和包装世界真相，不能生成世界状态。世界先发生事实，事件再决定如何让玩家看见；而不是事件随机抽到"背叛"，于是 A 突然背叛 B。
3. **玩家界面不得泄露认知之外的信息。** 界面展示的是玩家角色所知，而不是世界数据库。玩家的信息获取本身就是玩法。

**三层模型是信息架构，不是玩法权重声明。** 角色认知的差距会影响行动质量，但不得因此把个人实力、修炼与战斗降格为情报系统的附属。世界的权力仍然由武力、制度与关系共同支撑；信息是这三者之上的放大器，不是替代品。

> **非规范性示例（仅作说明）**：六番队三席实际上收受了某贵族的利益——这是世界真相；玩家是否知道、知道多少、从谁那里听来——这是角色认知；本月密报要不要报道、以什么措辞报道——这是玩家呈现。三件事必须分开存储、分开处理。

**可追溯的实现约束。** 任何关系变化与重要结果，都必须能够指向具体的事件与认知来源。关系边上应当能回答"这条关系为什么会变成这样"，答案必须引用具体历史条目，而不是一个抽象数值。

## 5. 时间与玩家行动

**行动消耗世界时间。** 修炼、任务、社交、政治经营、疗养、旅行，全部占用月或年级的时间单位。没有不花时间的操作，也没有只属于玩家的时间。

**世界不会因为玩家没有观察而停止。** 玩家闭关、重伤疗养、外出执行任务时，其他人物仍然在晋升、结盟、结婚、决斗、死亡、培养后辈、争夺职位、制造秘密、发动政治行动。玩家回到世界时，面对的是一个已经变化的世界，而不是离开时的存档快照。

**缺席是有代价的。** 长期离开不只是错过机会：关系需要维护，情报网会失效，派系中的位置可能被人顶替。玩家不在场时，世界不只是继续运转，还会主动重新分配玩家留下的空位。

**长期行动必须允许重大事件打断。** 闭关、远征、长期疗养这类跨越较长时间的行动，在被重大事件触发时，玩家应获得中断机会。是否中断是一个真实的决策：是继续修炼，还是立刻出关处理。

> **非规范性示例（仅作说明）**：
>
> 玩家闭关三年，预计 154 年 7 月结束。第 11 个月，导师遭到刺杀。
>
> [中断闭关]　[继续闭关]

**时间机会成本应当可见。** 在做出长期承诺之前，玩家应当能够感知"将错过什么"——已知的选拔窗口、婚丧、任务周期、政治日程，而不是未来的结果。让玩家自己计算机会成本，而不是替玩家隐藏成本。

**时间尺度的表述（设计意图）。** 短期是日与周级的行动与互动；中期是月与年级的政治与修炼结算；长期是十年与世代级的格局变迁。如何推进时间（日推、事件队列、连续时间戳、分级调度等）属于实现问题，见 OQ-03；时间尺度的分档方式见 OQ-04。

**时间成本的真实来源。** 由于角色的寿命跨度很长，时间成本的主要来源不是寿命本身，而是机会窗口与人事变迁。三年不会让一个死神变老，但三年足以让一个职位被别人拿走。

**人物会老去与死亡。** 受伤、衰老、死亡是世界的一部分；时间尺度因此可以跨越数十年到数百年（见第 12 章）。

## 6. 人物与关系

**人物不是属性集合。** 人物由六层构成：

```text
身份：年龄、出身、家族、所属组织
能力：基础素质 / 通用技艺 / 个体能力 / 异常能力
个性：野心、忠诚、勇气、自尊、同理心
社会：关系、师承、家族、派系
政治：职位、功绩、声望、影响力
心智：当前目标、恐惧、欲望、记忆
```

六层不是并列的六个数值面板：身份决定起点与限制，个性决定选择偏好，社会与政治决定他能动员什么，心智决定他现在想要什么。

**能力层不是五项技能值。** 能力层由四类性质不同的东西构成：基础素质、通用技艺、个体能力、异常能力。鬼道与斩魄刀分别属于不同性质的能力类别（见第 10 章）；具体分类语义、字段与数值属于《能力体系与战斗语义》文档。

**记忆与关系是两回事。** 关系是当前状态，记忆是历史条目。NPC 不应当只是"对玩家好感 -37"，而应当记得：你曾经救过我；你支持了我的竞争者；你在我最弱的时候羞辱过我；你是我老师的弟子。关系的变化应当能追溯到记忆条目，而不是无缘无故地漂移。记忆条目应当可以被引用——在对话里、在决策里、在玩家查询因果时。

**关系不是单一好感。** 关系至少包含好感、信任、敬畏、嫉妒、恐惧、义理、利益依赖等维度。"我讨厌你，但我信任你的能力"和"我很喜欢你，但绝不会让你成为队长"必须都能被表示，也必须都能被区分。这些互相矛盾的关系，正是政治模拟最有意思的地方。

**认知与秘密。** 每个角色拥有自己的认知集合；秘密是认知层的一等对象：谁持有秘密、谁知道了、是否真实、有没有证据、暴露的后果是什么。完整的秘密与情报机制属于后续系统文档。

**目标驱动。** 每个 NPC 拥有一个或多个当前目标，例如成为三席、学习始解、复仇、保护孩子、提升家族地位、接近某位队长、调查某个秘密、阻止竞争者晋升。目标是行动的源头，行动是世界历史的源头。NPC 如何评估与决策，属于《NPC 行为模型》文档。

**人物可以自相矛盾。** 人物不是效用函数的奴隶：忠诚可能压过利益，恐惧可能压过野心，自尊可能让人做出明知不利的选择。NPC 的行为模型必须允许个性压过理性计算——否则所有人物都会变成同一种精算机器，政治也就失去了味道。

**人物对活动本身存在偏好。** 同样一件事，不同人物的主观效用不同：有人厌恶战斗，只为功绩；有人享受战斗，主动寻找强敌；有人畏惧死亡，回避高风险任务；有人崇尚公平决斗；有人只打稳赢的仗。这意味着同一个职位、同一场任务，对不同角色的吸引力可能完全不同——人物不是按同一种算式挑选最优解的机器。

**成长受多重因素影响。** 天赋、导师、年龄、基础能力、训练方式、精神状态、伤势、资源都会影响成长速度与上限。年龄曲线意味着天赋存在窗口期，错过窗口的人不会因为活得久而自动变强。

## 7. 组织、职位与权力

**组织是世界的骨架。** 护廷十三队、番队、贵族家族、中央机构、学院、研究机构、隐秘组织，共同构成玩家生活的制度环境。组织不是背景板：它们分配任务、掌握资源、决定谁能被看见。

**真央灵术院是人才入口与社会流动节点。** 它既是玩家可能的开局场所，也是不同出身的角色第一次形成师生、同窗、竞争、派系与番队倾向的地方。学院时期形成的关系可以延续数十年，成为后来政治网络的早期来源。学院本身也是政治场所：教职任命、招生名额、番队招募偏好，都是可以被争夺的资源。

> **非规范性示例（仅作说明）**：开局路线可以完全不同——带着家族人脉入学的贵族子弟、靠天赋考入的流魂街出身者、被安排进某个番队的家族旁支、很早被队长关注的天才。具体开局的数量与差异见 OQ-13。

**职位是稀缺资源。** 队长、副队长、三席、四席……席位是有限的。职位带来的不是属性加成，而是权力、资源、指挥权、情报、声望、政治票权，以及培养下属、影响任免的能力。竞争职位的实质，是获得改变他人命运的能力。

**不同职位可以有不同规则。** 职位的产生、晋升、任命与罢免方式不必统一，也不应被统一成固定路线。制度差异本身就是番队特色的一部分：有的番队看重武力传统，有的看重门阀与资历，有的看重技术能力与机构政治，总队长则完全是另一套机制。具体的晋升算法与提名规则属于职位与任命系统文档（见 OQ-05）。

**空缺是政治机会。** 政治流动的起点是位置空出来。组织必须能够产生结构性的流动——阵亡、重伤退位、退役、调任、扩编、清洗、增设机构——否则模拟会在几十年内僵死，所有晋升故事都无从发生。空缺如何产生、频率如何，属于后续系统文档。

**多个权力中心并存。** 世界中的权力中心各自掌握不同类型的资源：有的掌握合法性与法统，有的掌握武力与暴力，有的掌握情报与记录，有的掌握人才管道，有的掌握财富与血统。政治的本质是跨资源交换，没有任何一个中心能单独决定一切。

**任务分配是日常政治。** 上级可以把危险任务派给政敌，把美差留给自己人；席官可以用任务安排培养、试探或消耗某人。这种每天都在发生的分配行为，是政治最日常、也最容易被低估的形态。玩家既会受它影响，也能在获得职位后使用它。

**权力伴随治理责任，但责任可以被委托；委托权力会创造新的权力中心。** 职位不是被动扣时间的负担，而是需要被履行的职能。担任者可以选择亲自处理、委托副职、委托席官、长期放任，或建立制度让其自动运转——每种选择都有不同的代价。当权力被长期委托出去，受托者会逐渐培养自己的亲信、影响任务分配、积累独立的人脉与忠诚。委托者保住了头衔，但可能失去实际控制力。

> **非规范性示例（仅作说明）**：队长长期闭关修炼，把日常事务交给副队长；副队长借此掌控任务分配、培养亲信，普通队员首先忠于副队长而不是队长——一个影子权力中心就此形成，并可能在某一天发动自己的政治行动。

**玩家能够影响组织。** 担任职位的人可以影响任命、任务分配、资源流向与下属培养。玩家在组织中获得的权力，必须真实地改变其他角色的处境，而不只是玩家面板上的数字。

## 8. 家族与派系

**家族是集体政治行为者。** 家族不是"贵族出身，声望 +20"这样的出身修正。它拥有成员、声望、资源、关系网络、制度影响力与长期利益，会评估形势、选择路线、投入资源、承受损失。

**家族利益可以跨越个人生命。** 家族的目标不会因为某一代人的死亡而结束。集中资源把某个年轻成员推上副队长，是一次典型的集体决策；决策失败，家族承担后果；决策成功，收益由整个家族分享。

**代理人政治。** 家族与派系会培养、扶植、交换候选人。个人与个人的竞争背后，往往是家族与家族的竞争；一个候选人的胜负，会改变两个家族十年后的力量对比。

**家族与派系的区别。** 派系是围绕利益、立场或关系形成的非正式联合，家族是血缘与制度构成的正式单位。一个人可以同时属于番队、家族、师门与派系，并且这些归属可能互相冲突——组织忠诚与家族忠诚的冲突，是政治戏剧最重要的引擎之一。

**家族机制的边界。** 联姻、过继、家督继承、秘传技法等具体机制不在本文件锁定，属于家族系统文档（见 OQ-07）。本文件只锁定：家族必须是行为者，而不是属性。

## 9. 个人成长

**修炼是主要的长期个人行动。** 成长方式包括个人训练、导师指导、实战磨炼、闭关、特殊突破。不同的方式有不同的时间成本、风险与收益结构。

**高级能力需要真正的长期投入。** 始解可能需要数月到数年，卍解可能需要数年甚至数十年。这会自然形成一种有趣的社会结构：有天赋的人不一定有时间修炼；队长事务缠身，基层人物权力虽小，却可能拥有更多自由时间——当然，队长可以把事务委托出去（见第 7 章），但委托的代价是权力中心的转移。自由时间本身就是一种资源。

**修炼成果必须能够兑现。** 修炼、始解、卍解与鬼道的成长，必须在战斗与威慑中有清晰体现——这是玩家长期投入最直观的回报，也是"实力是一等政治基础"成立的前提。

**师徒关系是政治纽带，不只是技能传授。** 师门带来资源、保护与人脉；导师的敌人可能成为你的敌人；导师的死亡会转移义务与仇恨。收徒同样如此：弟子是政治资产，也是政治风险。

**实战同时是成长与风险。** 功绩、伤势、仇恨、声望都从实战中产生。在战斗中变强的人，往往也在战斗中结仇。不同角色对战斗的主观偏好不同：有人厌恶，有人享受，有人畏惧死亡，有人崇尚公平决斗（见第 6 章）。因此实战对每个人的意义与风险也不同。

**机会成本贯穿始终。** 每一次长期修炼都是对政治机会的放弃；每一次政治经营也都是对修炼时间的放弃。这两者之间的选择，应当由玩家来做，而不是由系统给出最优解。

具体的成长曲线、训练公式与突破条件属于修炼系统文档。

## 10. 能力、冲突与战斗

### 能力体系的高层结构

**能力的两种性质。** 通用能力与个人能力是两类不同的东西。鬼道属于制度化、可传播的通用知识体系：它由学院、番队、鬼道众、导师与家族教学和保存，一名大师死亡后，其知识原则上仍可通过制度与学生延续。斩魄刀属于高度个体化的角色能力体系：它高度依附具体人物，具有不可替代性；某个特殊能力持有者的死亡、叛逃、受伤或转向另一组织，本身就可能改变组织的能力结构与政治格局。简言之：**鬼道是制度资本，斩魄刀是个人资本。**

**鬼道内容以整理既有知识库为主。** 原作及授权衍生作品已经存在大量有编号、有名称、有表现记录的鬼道；后续工作重点是资料整理、来源标注、结构化与规则化，而不是为了补齐编号而自动生成原创鬼道。允许编号空缺存在。来源层级与设定冲突的裁决政策见 OQ-15。

**斩魄刀采用受约束的生成模型。** 大量原创 NPC 意味着无法逐一人工编写所有斩魄刀，但斩魄刀不能从通用技能词条池中随机抽取：它必须与人物的人格、经历、欲望、恐惧与战斗倾向相关联，并遵守"能力语法/生成约束"。始解与卍解必须保持概念连续性——卍解是同一核心概念的深化、扩大、极端化、反转或完整表达，而不是重新获得一个无关的能力。

> **非规范性示例（仅作说明）**：可以用这样的概念链条理解斩魄刀生成——角色 → 核心主题 → 核心能力法则 → 作用方式 / 限制 / 代价 → 始解 → 卍解。具体的 schema 与语法规则属于《能力体系与战斗语义》文档（见 OQ-16、OQ-17）。

**能力不能被压缩成单一战力。** 能力可以具有战斗价值、情报价值、组织价值、治疗价值、调查价值、战略价值等；非战斗价值真实存在，并会直接进入政治与组织模拟。本文件不规定具体维度与评分公式。

**能力情报必须遵守三层世界模型。** 一个人的始解能力是什么，属于世界真相；不同人物可能只知道一部分、拥有错误认知或完全不知道，属于角色认知；玩家界面只能展示当前 POV 合理掌握的信息，属于玩家呈现。"未知能力"因此具有战略价值——但这不是"情报比实力更重要"：实力仍是战斗的基线，情报与准备改变的是胜负边界（见第 4 章）。

**战斗的定位。** 本作中的战斗，职责是让人物实力成为世界中真实有效的资本，而不是做成最好的战术游戏。战斗不需要华丽，但它必须改变世界。

**允许高度抽象。** 准备、交锋、结果（伤势、死亡、逃跑、胜负），一个最小循环就足以成立。具体战斗机制属于战斗系统文档。

**实力是战斗的基线，备战改变胜负边界。** 实力决定区间，情境决定区间内的结果（Power establishes the range; circumstance decides within the range）。情报、克制、队友、准备、环境、疲劳与伤势都会影响结果，但它们影响的是边界内的胜负，而不是无上限地改写实力差距。

**实力差距决定备战的作用空间（设计意图，阈值不锁）。**

```text
差距较小 → 情报、准备、环境、协作可以决定结果
差距中等 → 充分准备可以制造爆冷可能
差距极大 → 普通准备无法弥补，需要特殊条件、顶级协同、异常能力或制度手段
```

**非对称必须存在，但有边界。** 如果实力差距是唯一决定因素，政治、情报与智谋就会被数值吞噬；因此必须保留以弱胜强的空间。但非对称路径以三档差距为界，差距越大越依赖特殊条件；政治与制度手段（借势、规则、合谋、借刀杀人）也是弱者对抗强者的正规路径，而不只是正面战斗的替代品。

**能力谱系必须有自己的表现空间。** 斩魄刀与始解/卍解、鬼道、白打、瞬步，是战斗差异的主要来源。战斗设计必须让这些能力真正说话，而不是被单一数值或纯情报操作淹没。

**灵压是双重存在。** 灵压既是战斗的基础，也是社会存在感——压迫、威慑、无声的谈判筹码。因此灵压天然是政治工具，不能简化为一维战力条。

**战后管线比战斗本身重要。** 一场战斗的政治后果包括：伤亡、功绩、仇恨、声望、心理影响、职位空缺、政治后果、情报泄露（招式被看破）、名声信号（谁活着回来了）。一场虚讨伐战中副队长阵亡，对战斗系统只是一个死亡结果；对政治模拟来说，整个番队未来二十年的格局被改变了。这就是战斗存在的意义。

## 11. NPC 世界与历史

**NPC 自主行动。** 每个 NPC 拥有目标，并自主评估形势、制定计划、采取行动。世界历史主要来自人物欲望之间的碰撞，而不是大量手写脚本。理想的因果链是这样的：A 想晋升，B 占着职位，A 与 C 有关系，C 掌握 B 的秘密——于是事情自然发生。

**世界不是玩家剧场。** NPC 会晋升、结盟、结婚、决斗、死亡、培养后辈、争夺职位、制造秘密、发动政治行动，其中大多数与玩家无关。世界不会因为玩家闭关而暂停，也不会因为玩家在场才变得重要。

**事件系统的定位。** 事件负责表现和特殊情况，不负责驱动世界。模拟系统先算出"A 背叛了 B"，事件系统再把它呈现为"A 在队长会议前夕秘密倒向另一派系"；而不是随机抽到"背叛事件"，于是 A 突然背叛 B。这两个方向的差别，是本项目与普通事件驱动游戏的根本区别。

**历史必须被保存并被引用。** 保存历史不是为了百科，而是因为历史本身影响现在。十二年前朽木家支持现任队长上位，今天的队长仍然欠这份人情；三十年前玩家的导师杀死某人的父亲，今天那个人已经是另一番队的副队长。NPC 会引用旧事，旧事会改变关系与决策。

**规模是一个必须正视的约束。** 世界中的人物数量远大于可以被精细模拟的数量。如何分配模拟精度是一个待定问题（见 OQ-09）。本文件只锁定原则：精度分配必须服务于"重要变化可追溯"，而不是均匀地浪费在无人关心的角落。

**模拟覆盖与历史连续性。** 曾获得职位的角色必须进入个体模拟；失去职位不会让一个角色从世界中消失——曾经拥有职位、重要关系或历史价值的角色退入低频存在，并可在条件满足时（被重新拉拢、实力突破、旧怨被激活、职位空缺）重新进入前台。只有从未进入个体模拟、也未留下重要历史的背景人口，才适合聚合处理。

> **非规范性示例（仅作说明）**：可以用"活跃 / 潜伏 / 背景人口"三个层级来理解模拟精度——活跃人物高频完整模拟，潜伏人物低频模拟但身份持续存在，背景人口聚合模拟。具体的分级方案与计算预算属于实现问题（见 OQ-09）。

**呈现层的信息职责。** 什么时候让玩家看到什么，本身就是设计。密报、传闻、关系网、编年史、因果查询，都是呈现层的工作；玩家获取信息的过程本身就是玩法的一部分。呈现可以简陋——文本、表格、甚至终端界面都可以接受——但必须可读、可追溯、不撒谎。

**缺席期间的叙事必须补交。** 玩家闭关或远征归来时，世界发生的变化必须以可读、可追溯的形式交付——一份包含关键人事、关系变动与因果线索的回顾，而不是让玩家从一堆数值里自己猜。补交叙事属于呈现层，只负责汇报已经发生的事实。

## 12. 死亡、继承与长期游玩

**死亡是政治事件。** 人物会因重伤、战斗、刺杀、衰老而死亡。死亡会产生职位空缺、恩义转移、仇恨继承、家族兴衰，是世界运转的一部分。

**玩家角色也会死亡。** 玩家角色的死亡不是 Game Over，而是视点（POV）的切换。

**世界不重启。** 新视点进入的是同一个世界：全部历史、关系、组织与记忆继续存在。新角色面对一个已经活过的世界，而不是一份新的开局。这使游戏真正进入几十年到数百年的尺度，人物只是世界中的一段。

**继承的是世界与历史，不是前一角色的个人能力。** 继任者的实力、天赋与记忆从自身条件开始，不得直接继承前任的战力与技能。前一角色留下的东西，应当以世界状态的形式存在——职位（可能旁落）、关系、恩义、仇恨、声望、家族资产——而不是以数值遗产的形式塞进新角色面板。

**继承转移规则是核心问题。** 哪些关系、恩义、仇恨、资产与名望，会以什么方式影响继任者，属于继承系统的核心设计问题（见 OQ-06）。继承候选包括子嗣、弟子、家族成员、亲信等方向，具体机制属于后续文档。

**长期游玩没有单一胜利条件。** 玩家自行定义人生目标：成为队长、成为总队长、建立新兴家族、让弟子掌控多个番队、成为最强死神、在幕后影响中央政治、让衰败家族重新崛起。游戏不提供唯一的通关答案，也不评价哪种人生更正确。

## 附录 C：原型证伪指标

**目的。** 第一阶段原型不验证"好不好玩"，只验证企划的核心假设是否成立。

**切片配置。**

- 3 个组织：六番队、十一番队、某贵族家族
- 30～50 名 NPC
- 3 个家族
- 8～12 个稀缺职位；职位之间必须存在跨组织、可比较的吸引力（否则无法测试"组织忠诚 vs 家族忠诚"）

**允许的简化。** 能力 3 项、关系 3 轴、行动 6 种、政治只做职位竞争、修炼只做普通训练、战斗使用简化 resolver。所有系统都可以浅，但不允许跳过"多人、多组织、多关系同时运行"这个前提。

**阶段一。** 不加入玩家，纯模拟运行 20 年，观察世界自发演化。

**阶段二。** 加入玩家扰动（例如争夺一个职位），观察世界的反应；额外观察项：玩家的干预能否进入可追溯因果链（暂不作为第四个正式证伪指标）。

**三个正式证伪问题。**

1. **世界会不会自己产生冲突？** 不给任何特殊待遇，20 年内能否自发出现这类链条：职位竞争 → 拉拢 → 结盟 → 得罪竞争者 → 秘密暴露 → 晋升 → 新的空缺。若不出现，NPC 模型失败。
2. **冲突有没有历史连续性？** 是否能看到：第 3 年发生冲突 → 第 7 年仍然影响合作 → 第 11 年因共同敌人暂时结盟 → 第 16 年旧账再次产生影响。如果过去不影响现在，记忆系统失败。
3. **我们能不能解释发生了什么？** 对任意重要事件（例如"为什么 A 成了副队长"），系统必须给出支持与反对因素清单：实力合格、资历较高、队长信任、家族支持、曾救过副队长；以及 B 虽然更强，但与队长有旧怨、当前重伤、缺少政治支持。若只能输出类似 `score(A) = 87.42` 的单一分数，视为失败——可解释性是本项目的核心目标之一。

**通过标准。** 三个问题全部通过，才进入内容扩展；任何一个失败，回到对应系统文档修改，而不是在原型上打补丁。

## 附录 D：术语

| 术语 | 定义 |
|---|---|
| 世界真相（World State） | 世界的客观完整状态，不因观察者改变。 |
| 角色认知（Knowledge） | 单个角色对真相的掌握子集，带来源与置信度。 |
| 玩家呈现（Presentation） | 经选择、延迟、包装后交给玩家的信息通道。 |
| 席位 / 职位 | 组织中的稀缺位置，附带权力、资源与影响他人的能力。 |
| 功绩 | 由任务与战斗产生的、可被组织承认的贡献记录。 |
| 声望 | 他人对一个人的公开评价，可能偏离真实。 |
| 恩义 | 人与人、人与组织之间未结清的义务，是政治交易的现货。 |
| 秘密 | 认知层的一等对象：谁知道、是否真实、有无证据、暴露后果。 |
| 传闻 | 可能为真的公开信息，传播快、可被操纵。 |
| 派系 | 围绕利益、立场、关系形成的非正式联合。 |
| 门阀 | 血缘与制度构成的正式政治行为者。 |
| POV | 当前玩家视点人物。 |
| 可追溯因果 / 可解释性 | 重要变化能追溯到具体经历、认知与行动，并以因素清单形式解释。 |
| 制度资本 / 个人资本 | 鬼道依附制度、可教学可传承；斩魄刀依附个人、不可替代——二者在政治模拟中的性质区别。 |
| 能力语法 | 斩魄刀生成的受约束结构：从核心主题到始解、卍解的连续性约束，而非自由文本随机生成。 |
| 通用能力 / 个人能力 | 通用能力是制度化、可传播的知识体系；个人能力是角色绑定的个体化能力。 |
| 非规范性示例 | 仅用于说明设计意图的示例，不构成实现规格。 |
| 证伪指标 | 用于判断核心假设是否成立的验收问题。 |

## 附录 E：未来系统文档清单

按优先级排列。每份文档的产出都必须能回答它对应的开放问题，并接受本文件的约束。

1. **NPC 行为模型**——NPC 是什么、如何评估与决策、记忆如何影响行动。最高优先级：本游戏一半以上的成败取决于它。
2. **能力体系与战斗语义**——鬼道的结构化语义、斩魄刀能力语法、始解/卍解关系、能力在非战斗场景的作用、NPC 如何理解与比较能力。不生产完整鬼道表，也不负责批量生成斩魄刀实例（对应 OQ-15、OQ-16、OQ-17）。
3. **世界状态与数据模型**——世界如何被描述；人物、关系、组织、历史的数据结构。
4. **时间与调度**——时间推进模型、行动队列、中断机制（对应 OQ-03、OQ-04）。
5. **情报与秘密**——秘密对象、认知传播、探听、要挟、放风、情报网。
6. **职位与任命**——席位、空缺产生、晋升、任命、罢免规则（对应 OQ-05）。
7. **家族与派系**——家族资源、集体决策、联姻与继承机制（对应 OQ-07）。
8. **修炼与成长**——训练方式、成长曲线、突破条件、走火入魔与风险。
9. **战斗**——实力基线、备战、交锋、结果与战后管线（对应 OQ-12）；解算流程归本文件，能力语义归《能力体系与战斗语义》。
10. **叙述呈现与信息分诊**——密报、传闻、编年史、因果查询；什么信息在什么时候给玩家。
11. **继承**——POV 切换、继承转移规则、继承者生成（对应 OQ-06）。
